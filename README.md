# Hennycam.live

This repository contains a simple static starter site (HTML/CSS/JS).

Files included:
- index.html
- css/styles.css
- js/script.js

To run locally:
1. Clone the repo
2. Open index.html in your browser or run a local server:
   python -m http.server 8000
   then open http://localhost:8000

To publish with GitHub Pages:
1. In the repository Settings → Pages, choose the branch (main) and folder (root) as source.
2. Save and wait a minute for the site to become available.
